# Reflection: Computer Graphics & Digital Image Processing

**Date:** 06/08/2026

The lecture introduced me to the fundamentals of Computer Graphics and Digital Image Processing. I learned that computer graphics focuses on creating images, while image processing focuses on analyzing or improving existing images.

We discussed geometric primitives such as points, lines, curves, and polygons, and how mathematics and calculus are connected to drawing curves. We also learned about Java graphical frameworks such as JavaFX, along with the Event Listener Model used to handle user interactions.

Another important topic was the difference between static and interactive graphics, as well as vector and raster graphics. I learned that static graphics remain unchanged after they are displayed, while interactive graphics can respond to user actions such as mouse clicks or keyboard input and update the display through repainting. We also discussed vector graphics, which represent images using mathematical shapes and can be scaled without losing quality, and raster graphics, which are made up of pixels and may lose quality when enlarged. Understanding this difference helped me see why different types of graphics are suitable for different applications. I also learned about accessing GitHub repositories using SSH and HTTPS and how public and private keys are used for secure authentication.

## Key Takeaways

- Computer Graphics vs. Digital Image Processing
- Geometric primitives 
- Static vs. interactive graphics
- Vector vs. raster graphics
- Connection between graphics and calculus
- Secure GitHub access using SSH and HTTPS
