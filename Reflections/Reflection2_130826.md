# Reflection 2: Computer Graphics & Digital Image Processing

**Date:** 13/08/2026

In this lecture, I learned about Maven and its role in managing Java projects. I learned how Maven provides a standard project structure and uses the pom.xml file to manage project configuration and dependencies. We created a basic Maven project and learned how to use commands such as mvn clean package to build the project. I also learned that Maven commands must be executed from the correct project directory containing the pom.xml file.

We also worked with Java Swing and the Graphics and Graphics2D classes to create a graphical application. I created a window that displayed a hollow square and learned how to control its position, size, color, and line thickness. By using BasicStroke, I was able to increase the width of the square's outline, while calculating the coordinates based on the window dimensions allowed the square to remain centered.

I also encountered practical issues such as running Maven from the wrong directory and trying to rename a folder while it was being used by another process. Solving these problems helped me better understand project organization, command-line tools, and basic troubleshooting in a development environment.
