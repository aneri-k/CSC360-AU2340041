## Notes

### Topic 1: Markdown and Reflection Writing

The lecture started with a review of reflection journals written by other students. This helped me understand how a good reflection should be structured and what kind of information should be included. We discussed that a reflection should not simply list everything done during the lecture, but should explain what was learned and understood.

We also reviewed basic Markdown formatting, such as headings, spacing and proper organization of content. Looking at other students' reflections helped me identify areas where I could improve the structure and clarity of my own reflections.

---

### Topic 2: Java 2D and Drawing

We continued with the basics of creating graphics using Java. A `JFrame` acts as the main window or container, while a `JPanel` provides the area where the actual drawing takes place.

The drawing is generally performed by overriding the `paintComponent()` method of the panel. We also learned that `super.paintComponent()` should be called before adding our own drawing instructions. The `Graphics` object can also be converted to `Graphics2D` when more advanced drawing features are required.

Understanding the difference between the `JFrame` and `JPanel` helped me better understand how a Java graphics application is organized.

---

### Topic 3: Shapes, Coordinates and OOP

The lecture also connected Object-Oriented Programming concepts with computer graphics. We discussed classes, subclasses and inheritance, and how a subclass can extend an existing class to add its own functionality.

We also continued working with points and coordinates to create different shapes. A rectangle can be defined using two points, while a triangle requires three points. Therefore, the coordinates need to be selected carefully when creating a triangle.

The Triangle Inequality Theorem was also discussed as a way of checking whether three points can form a valid triangle. This showed how mathematical concepts can be useful when implementing graphical applications.
